# 📊 Dashboard de Vendas - Assinaturas Xbox

## 📝 Descrição do Projeto
Este projeto é a solução para o desafio prático de criação de um **Dashboard de Vendas** no Excel. O objetivo principal foi estruturar e transformar dados brutos de assinaturas (Xbox Game Pass, EA Play, Minecraft, etc.) em informações visuais claras e interativas. O painel construído permite uma análise eficaz do desempenho de faturamento, planos e categorias, facilitando a tomada de decisões baseadas em dados.

## 🛠️ Ferramentas e Recursos Utilizados
- **Microsoft Excel**
- Limpeza e Modelagem de Dados
- Tabelas Dinâmicas (Pivot Tables)
- Gráficos Dinâmicos
- Segmentação de Dados (Slicers) para interatividade
- Formatação Condicional e Design de Interface (UI)

## 📂 Estrutura do Repositório
- `dashboard_xbox.xlsx`: Arquivo principal contendo a base de dados, a aba de cálculos auxiliares e o dashboard final interativo.
- `README.md`: Documentação explicativa do projeto.
